# STORY.md — AI 网关企业落地汇报

## 1. 故事主线（Narrative Spine）

> **大模型在企业里缺一个"总闸门"，我们用一个内网 AI 网关把这件事做成。**

四幕剧结构，每幕一组页面：

| 幕 | 主题 | 页面 | 核心价值 |
|---|---|---|---|
| **开场** | 痛点共鸣 + 划清边界 | P1-4 | 让听众点头——"这事确实存在" |
| **方案** | 项目是什么、架构长啥样、能干啥 | P5-7 | 让听众明白——"这个工具能干这事" |
| **场景** | 落到企业里的两类典型场景 | P8-11 | 让听众代入——"我部门也是这情况" |
| **落地** | 5 个关键抓手（含路线图） | P12-17 | 让听众行动——"这周可以先动起来" |
| **收尾** | 边界诚实 + 下一步 | P18-19 | 让听众信任——"这帮人知道自己在做什么" |

## 2. 受众与心理路径

- **第一受众：管理层**（业务/IT 负责人）——关心：能不能用？花多少？有什么风险？
- **第二受众：技术团队**——关心：架构怎么搭？API 怎么接？扩展性如何？
- **混合汇报策略**：每页文字量适中（≤60 字/段），代码块/截图给技术看，业务价值句给管理层看

## 3. 节奏控制

- **前 4 页**节奏紧凑，痛点连环击，标题大字少字
- **中 12 页**信息密度高，多列、多图、代码块，**避免大段文字**
- **后 3 页**回到金句与行动建议，语气收束

## 4. 关键金句（贯穿全篇）

- "**把大模型变成公司的'自来水'**"——价值锚点
- "**敏感度决定部署位置，不是能力决定**"——场景决策
- "**诚实的边界 = 可信的产品**"——收尾信任
