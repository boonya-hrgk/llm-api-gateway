# DESIGN.md — AI 网关企业落地汇报

> 走通用设计原则（场景为企业内部技术方案汇报，不命中"学术/咨询/党政"三类预设风格）。
> 调性：商务咨询 × 极简技术派，大留白、信息密度高、深蓝主色。

---

## 1. 画布与字体

- **画布**：1280 × 720 px（16:9）
- **中文字体**：思源黑体（Source Han Sans）/ 微软雅黑
- **英文字体**：Inter
- **代码字体**：JetBrains Mono / Cascadia Code
- **正文字号**：18-20px
- **标题字号**：32-48px
- **强调字号**：60-72px（封面/分隔页主标题）

## 2. 色板（≤ 4 种主色 + 状态色）

| 角色 | 色值 | 用途 |
|---|---|---|
| **主色（深蓝）** | `#1F3A8A` | 标题、分隔页、关键强调 |
| **辅色（中性灰）** | `#475569` | 正文、说明 |
| **底色（白）** | `#FFFFFF` | 页面背景 |
| **点缀（青蓝）** | `#0EA5E9` | 代码块、链接、图示 |
| **状态·已实现** | `#10B981`（绿） | ✅ 标签 |
| **状态·集成** | `#2563EB`（蓝） | 🔌 标签 |
| **状态·路线图** | `#F59E0B`（黄） | 🟡🛣 标签 |
| **风险·边界** | `#DC2626`（红） | "不解决"提示 |

## 3. 排版三区（每页统一）

```
┌──────────────────────────────────────┐  0
│  A. 标题区（0-120px）               │  80-120
├──────────────────────────────────────┤
│                                      │
│  B. 内容区（120-660px）              │  540
│  留白率 ≤ 35%                       │
│                                      │
├──────────────────────────────────────┤
│  C. 页脚条（660-720px）              │  60
│  左：项目副标题  右：页码 NN/19      │
└──────────────────────────────────────┘  720
```

- **标题块**：左侧大标题（32-40px，主色），不塞装饰小图
- **内容区**：最多 2-3 列，主色/辅色/状态色面积比 ≈ 5:3:2
- **页脚**：60px，左侧小字副标题，右侧页码

## 4. 视觉锚点规则

- **每页必须 ≥ 1 个视觉锚点**：≥ 44px 元素 或 ≥ 40% B 区面积的图
- **连续两页版式不重复**：避免视觉疲劳
- **hero 页**（P1/P8/P12）必须 ≥ 48px 锚点数字 或 ≥ 40% 主视觉
- **支持页**（P9-11/13-17）控制视觉投入，文字+图标为主

## 6. 代码块样式

- **底色**：`#0F172A`（深石板色）
- **文字**：`#E2E8F0`（浅灰）
- **关键字高亮**：青蓝 `#0EA5E9`
- **圆角**：8px
- **行高**：1.5
- **行内留白**：水平 24px，垂直 18px
